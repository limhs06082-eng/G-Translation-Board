# G-번역보드 0.7.1 사용 설명서

G-번역보드는 교사 또는 학생이 마이크를 사용해 번역 자막을 띄우는 Windows 수업 도구입니다. 마이크 하나로 한 방향만 사용하거나, 서로 다른 마이크 두 개로 양방향을 동시에 사용할 수 있습니다.

- 교사: 한국어 음성 → 중국어, 러시아어, 프랑스어 또는 베트남어 자막
- 학생: 중국어, 러시아어, 프랑스어 또는 베트남어 음성 → 한국어 자막
- 기본 모드: 음성 인식과 번역을 PC 안에서 처리하는 로컬 번역
- 개인정보: 음성 파일, 인식 문장, 번역 기록을 저장하지 않음

## 1. 준비물

- Windows 10 또는 Windows 11 64비트 PC
- 교사용 또는 학생용 마이크 1개 이상
- 양방향 동시 사용 시 서로 다른 마이크 2개
- 최초 모델 준비 때 사용할 인터넷 연결과 충분한 저장 공간

블루투스 이어폰 2개를 동시에 연결할 수는 있지만, 두 마이크의 동시 입력 가능 여부는 PC의 블루투스 어댑터와 Windows 드라이버에 따라 달라질 수 있습니다. 두 이어폰 모두 Windows의 `설정 > 시스템 > 소리 > 입력`에 마이크로 표시되는지 먼저 확인하세요.

## 2. 설치

1. `G-번역보드_0.7.1_x64-setup.exe`를 실행합니다.
2. Windows가 알 수 없는 게시자 경고를 표시하면 파일 이름과 버전을 확인한 뒤 설치를 진행합니다.
3. 설치가 끝나면 시작 메뉴나 바탕 화면에서 `G-번역보드`를 실행합니다.

교사는 Python, Node.js, 별도 번역 프로그램을 설치할 필요가 없습니다.

## 3. 처음 사용하는 순서

### ① 번역 언어

학생 언어를 선택합니다.

- `중국어 간체`: 중국 본토에서 주로 사용하는 표기
- `중국어 번체`: 대만 등에서 주로 사용하는 표기
- `러시아어`: 러시아어 음성과 자막
- `프랑스어`: 프랑스어 음성과 자막
- `베트남어`: 베트남어 음성과 자막

`로컬 번역`을 선택하면 번역 API 키가 필요하지 않습니다. 처음 사용할 때만 모델을 내려받으며, 준비가 끝난 뒤에는 인터넷 없이 번역할 수 있습니다.

- 중국어 번역 모델: 약 1.2GB
- 러시아어·프랑스어·베트남어 공용 번역 모델: 약 650MB, 비영리 수업용 라이선스(CC-BY-NC 4.0)
- Whisper 음성 인식 모델: 선택한 `빠름`, `균형` 또는 `정확도 우선` 모델을 최초 1회 준비

### ② 마이크 연결

1. 교사 자막만 필요하면 `교사 마이크`만 선택합니다.
2. 학생 자막만 필요하면 `학생 마이크`만 선택합니다.
3. 양방향 자막이 필요하면 두 항목에 서로 다른 마이크를 선택합니다.
4. 사용하지 않을 역할은 `선택 안 함`으로 둡니다.
5. 말할 때 선택한 장치의 `입력 레벨`이 움직이는지 확인합니다.
6. 주변 소리가 많이 잡히면 `입력 민감도` 값을 낮춥니다.
7. 작은 목소리가 잘 잡히지 않으면 민감도 값을 한 단계씩 높입니다.

교사와 학생에게 같은 장치를 동시에 지정할 수 없습니다. 마이크를 하나만 선택하면 해당 방향의 자막 한 줄만 표시됩니다.

같은 이름의 마이크가 여러 개 보이면 이름 앞의 연결 방식을 확인하세요. 일반적으로 `[Windows WASAPI]`를 먼저 사용하고, 시작되지 않으면 `[MME]`를 선택하세요. `[Windows WDM-KS]`는 일부 PC에서 시작되지 않을 수 있습니다.

### ③ 자막 준비

1. 사용할 마이크가 하나 이상 선택되었고 번역 언어가 올바른지 확인합니다.
2. `자막 보기`를 눌러 자막 창을 표시합니다.
3. `번역 시작`을 누릅니다.
4. 상태가 `듣는 중`으로 바뀌면 선택한 역할이 말합니다. 교사는 한국어로, 학생은 선택한 언어로 말합니다.
5. 끝낼 때는 `번역 중지`를 누릅니다.

프로그램을 종료하면 자막 창도 함께 종료됩니다.

## 4. 보조 모니터와 전자칠판에 자막 띄우기

1. `상세 설정`을 누릅니다.
2. `자막 표시 화면`에서 전자칠판이 연결된 보조 화면을 선택합니다.
3. `자막 위치 잠김`을 눌러 `자막 위치 편집 중`으로 바꿉니다.
4. 전자칠판에 표시된 자막 창을 마우스로 끌어 원하는 위치로 옮깁니다.
5. 다시 눌러 위치를 잠그고 저장합니다.

화면을 새로 연결했는데 목록에 없다면 `화면 목록 새로고침`을 누르세요. `선택 화면 상단 중앙으로 이동`을 누르면 자막 창을 빠르게 기본 위치로 되돌릴 수 있습니다.

## 5. 자막 모양 조절

`상세 설정`에서 다음 항목을 조절할 수 있습니다.

- 자막 창 가로·세로 크기
- 자막 글자 크기
- 자막 배경 불투명도
- 문장 종료로 판단할 침묵 시간
- 자막 위치 잠금과 마우스 클릭 통과

`자막 미리보기`로 실제 수업 전에 크기와 위치를 확인하는 것을 권장합니다.

## 6. 음성 인식 속도 선택

`상세 설정`의 음성 인식 설정에서 PC 성능에 맞게 선택합니다.

- `빠름 / Whisper tiny`: 속도를 우선할 때
- `균형 / Whisper base`: 일반적인 중국어·러시아어·프랑스어 수업의 기본값
- `정확도 우선 / Whisper small`: 베트남어 권장. 베트남어를 새로 선택하면 자동 적용

`small`은 처음 사용할 때 약 500MB를 추가로 내려받습니다. 로컬 FLEURS 베트남어 100문장 비교에서 단어 오류율은 `base` 42.53%에서 `small` 24.29%로 낮아졌고, 처리 속도는 실제 음성보다 약 9.2배 빨랐습니다. 최대 메모리 사용량은 약 745MB였습니다. 실제 교실에서는 학생 목소리, 소음, 마이크 거리에 따라 정확도가 더 낮아질 수 있습니다.

자막이 늦게 뜨거나 PC가 버벅이면 `균형` 또는 `빠름`을 선택하세요. 0.7.0에서 이미 베트남어를 선택해 저장한 PC는 `상세 설정 > 음성 인식 > 정확도 우선`을 한 번 선택해 주세요.

## 7. 실제 수업 전 5분 점검

1. 선택한 교사 마이크에 말했을 때 교사 입력 레벨이 움직이는지 확인합니다.
2. 선택한 학생 마이크에 말했을 때 학생 입력 레벨이 움직이는지 확인합니다.
3. 교사 마이크를 사용한다면 한국어가 선택한 학생 언어 자막으로 나오는지 확인합니다.
4. 학생 마이크를 사용한다면 중국어, 러시아어, 프랑스어 또는 베트남어가 한국어 자막으로 나오는지 확인합니다.
5. 자막 창이 전자칠판의 원하는 위치에 표시되는지 확인합니다.
6. 프로그램을 종료했을 때 자막 창도 함께 사라지는지 확인합니다.

## 8. 문제가 있을 때

### 블루투스 마이크가 목록에 없음

1. Windows `설정 > Bluetooth 및 장치`에서 이어폰 연결을 확인합니다.
2. Windows `설정 > 시스템 > 소리 > 입력`에 해당 이어폰 마이크가 있는지 확인합니다.
3. 앱에서 `새로고침`을 누릅니다.
4. 그래도 없으면 앱을 완전히 종료한 뒤 다시 실행합니다.

음악 재생용 출력(A2DP)만 연결되고 통화용 마이크(HFP)가 활성화되지 않으면 앱 목록에 마이크가 나타나지 않을 수 있습니다.

### 번역 시작 직후 다시 멈춤

1. 화면에 표시되는 실제 오류 문구를 확인합니다.
2. 같은 이름의 마이크 중 `[Windows WASAPI]` 장치를 먼저 선택합니다.
3. WASAPI도 시작되지 않으면 `[MME]` 장치를 선택합니다.
4. `[Windows WDM-KS]` 장치는 피하고 다시 시작합니다.
5. 앱은 일시적인 장치 시작 실패를 한 번 자동으로 재시도합니다. 그래도 실패하면 Windows 소리 설정에서 해당 마이크의 입력 레벨을 확인합니다.

### 상태는 듣는 중인데 자막이 나오지 않음

1. 선택한 마이크의 입력 레벨이 움직이는지 먼저 확인합니다.
2. 입력 레벨이 없으면 Windows 입력 장치와 앱의 마이크 선택을 다시 확인합니다.
3. 입력 레벨은 있지만 자막이 없으면 모델 준비가 끝났는지 상태 메시지를 확인합니다.
4. 마이크 두 개를 사용한다면 교사와 학생 마이크를 서로 바꿔 선택해 장치 문제인지 역할 설정 문제인지 확인합니다.

### 주변 학생 목소리가 너무 많이 들어옴

- 해당 마이크의 입력 민감도를 1단계씩 낮춥니다.
- 마이크를 발화자 입 가까이에 둡니다.
- Windows의 자동 마이크 증폭 기능이 켜져 있다면 낮춰 봅니다.

### 자막이 다른 모니터에 표시됨

`상세 설정 > 자막 표시 화면`에서 보조 화면을 다시 선택하고 `선택 화면 상단 중앙으로 이동`을 누릅니다.

## 9. 개인정보와 외부 전송

- `로컬 번역`: 음성 인식과 번역을 PC 안에서 처리합니다. 최초 모델 다운로드 외에는 번역 API가 필요하지 않습니다.
- `Google Cloud`: 사용자가 직접 선택하고 API 키를 설정한 경우에만 인식된 문장을 Google 번역 서비스로 전송합니다.
- 원시 음성 파일, 인식 문장, 번역 결과를 앱이 파일이나 데이터베이스에 저장하지 않습니다.

학생 개인정보 보호가 중요한 학교 수업에서는 `로컬 번역` 사용을 권장합니다.
