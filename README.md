# G-번역보드 v0.7.1

G-번역보드의 첫 공개 버전입니다.

## 주요 기능

* 교실 수업용 실시간 번역 기능
* 교사와 학생이 쉽게 사용할 수 있는 직관적인 화면
* Windows 설치형 프로그램
* 수업 상황에서 빠르게 사용할 수 있도록 단순한 사용 구조 적용

## 지원 환경

* Windows 10
* Windows 11

## 설치 방법

아래 **Assets**에서 설치파일을 다운로드한 뒤 실행해 주세요.

권장 파일:

`G-Translation-Board-Setup-v0.7.1.exe`

## 설치 시 참고

개인이 제작한 무료 프로그램이므로 Windows에서 `알 수 없는 게시자` 또는 `Windows의 PC 보호` 안내가 표시될 수 있습니다.

공식 GitHub 저장소 또는 공식 블로그에서 다운로드한 파일인지 확인한 뒤 설치해 주세요.
